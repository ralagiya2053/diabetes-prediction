# Diabetes Prediction API

End-to-end ML deployment: a diabetes risk classifier served as a containerized FastAPI app on AWS Lambda.

## Architecture

\`\`\`
Browser (index.html)
   ↓  POST /predict
AWS Lambda Function URL
   ↓
Lambda Web Adapter (translates Lambda events → HTTP)
   ↓
FastAPI (app/main.py)
   ↓
model.pkl + scaler.pkl + encoder.pkl + feature_order.json
\`\`\`

## Stack

- **Model**: Logistic Regression (scikit-learn), 94.8% accuracy
- **API**: FastAPI + Pydantic
- **Container**: Docker (python:3.11-slim)
- **Registry**: Amazon ECR
- **Runtime**: AWS Lambda (container image) + Function URL
- **Frontend**: Static HTML + vanilla JS

## Frontend
The live frontend is available at: [https://ralagiya2053.github.io/diabetes-prediction/frontend/index.html]

## Project Layout

\`\`\`
app/           FastAPI service (main.py, schema.py)
frontend/      Static HTML UI
model/         Trained artifacts (generated by train/train.py)
train/         Training script + dataset
tests/         Pytest suite
Dockerfile     Container build
\`\`\`

## Docker

\`\`\`bash
docker build --platform linux/amd64 --provenance=false -t diabetes-api .
docker run -p 8000:8000 diabetes-api
\`\`\`

## Deploy

1. Push image to ECR:
   \`\`\`bash
   aws ecr get-login-password --region us-east-1 | docker login --username AWS --password-stdin <ACCOUNT_ID>.dkr.ecr.us-east-1.amazonaws.com
   docker tag diabetes-api:latest <ACCOUNT_ID>.dkr.ecr.us-east-1.amazonaws.com/diabetes-api:latest
   docker push <ACCOUNT_ID>.dkr.ecr.us-east-1.amazonaws.com/diabetes-api:latest
   \`\`\`
2. In Lambda console: **Deploy new image** → select \`latest\`.
3. Hit the Function URL: \`GET /health\`, \`POST /predict\`.

## API

\`\`\`json

  "hypertension": 0,

  "smoking_history": "never",
  "bmi": 27.32,
  "HbA1c_level": 6.6,
  "blood_glucose_level": 80
}
\`\`\`

Response:
\`\`\`json
{"prediction": 0, "probability": 0.044}
\`\`\`

## Notes

- Scaler and encoder are persisted and reapplied at inference — guarantees training/serving parity.
- Lambda Web Adapter lets the FastAPI app run unchanged on Lambda.
- Model artifacts are gitignored; regenerate via \`train/train.py\`.
